## Sobre o Projeto

**Pizza Earth** é um jogo de plataforma e aventura desenvolvido utilizando **Unity 6.0**.

O projeto foi criado por estudantes da **ETEC Dr. José Rodrigues Alckmin** e teve como objetivo aplicar, na prática, conhecimentos relacionados ao desenvolvimento de jogos, programação, game design e organização de projetos.

## Como Jogar

O repositório contém um arquivo `.zip` com a **build pronta do jogo**, portanto não é necessário instalar a Unity para executá-lo.

1. Acesse o repositório e localize o arquivo `.zip` da build.

2. Faça o download do arquivo.

3. Extraia todo o conteúdo do `.zip` para uma pasta de sua preferência.

4. Dentro da pasta extraída, localize o arquivo executável do jogo (`.exe`).

5. Execute o arquivo para iniciar o **Pizza Earth**.

> **Importante:** não mova apenas o arquivo `.exe` para outro local. Os demais arquivos e pastas presentes na build são necessários para que o jogo funcione corretamente.

Uma build da Unity normalmente possui uma estrutura semelhante a esta:

```text
PizzaEarth/
├── PizzaEarth.exe
├── PizzaEarth_Data/
├── UnityPlayer.dll
└── ...
```

Mantenha esses arquivos juntos na mesma pasta após a extração.

## Contexto

O Pizza Earth representa uma etapa inicial do meu aprendizado com desenvolvimento de jogos.

Por ter sido desenvolvido durante o ensino médio e em uma fase inicial de contato com a Unity, algumas implementações possuem limitações técnicas, principalmente relacionadas à física e a comportamentos condicionados ao *framerate*.

Ainda assim, o projeto foi fundamental para adquirir experiência prática com desenvolvimento de jogos e serviu como base para projetos posteriores.
