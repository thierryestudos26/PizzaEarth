# PizzaEarth
Jogo de plataforma e aventura desenvolvido em Unity 6.0 como projeto estudantil da ETEC Dr. José Rodrigues Alckmin. Desenvolvido por uma equipe de quatro integrantes, envolvendo programação em C#, game design, direção criativa, arte e produção sonora, com Thierry Monteiro atuando principalmente na Direção de Jogo e Direção de Programação.
